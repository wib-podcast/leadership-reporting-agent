# Leadership Reporting Agent

> **From the What I Built (WIB) podcast, Episode 01.** Placeholder: the build is coming soon.

An agent that turns a PM's scattered project signals into leadership-ready status reports.

## Inputs

- **Gmail** - client communication, timelines
- **Slack** - important channel messages
- **Notion** - release notes
- **Google Docs and Sheets** - PRDs, client-facing FRDs, project trackers
- **Jira** - delivery and program tickets, milestones
- **Meeting transcription (e.g. Read.ai)** - client and leadership meeting notes

## Outputs

- Client-wise status reports
- Timeline-wise status reports
- Recurring leadership reports and decks (weekly status review, Product x Sales connect)
